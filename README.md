# Mofan2020 Tap

## How do I install these formulae?

`brew install mofan2020/tap/<formula>`

Or `brew tap mofan2020/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mofan2020/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
